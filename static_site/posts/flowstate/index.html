នៅក្នុងខ្លួនយើងទាំងអស់គ្នាមាន Mental State មួយដែលជួយអោយផលិតភាពកើនឡើងខ្ពស់, ហើយភាពសប្បាយបានមកដោយមិនពិបាក។

តើជាអ្វីទៅ?

វាត្រូវបាហៅថា Flow State

អីគេទៅជា Flow state?

Flow state គឹនិយាយពាក់ព័ន្ធទៅនឹង powerful mental zone ហើយវាកើតឡើងនៅពេលដែលយើង​ចូលជ្រៅទៅក្នុងសកម្មភាពមួយ, ផ្ដោតអារម្មណ៍ទាំងស្រុង, និងអនុវត្តបានដល់កំពូល និងល្អបំផុត។

ដែលធ្វើយើងមានអារម្មណ៍ថាពេលវេលាដើរលឿន, ការរំខានក៏លែងមាន, ហើយផ្ដោតលើអ្វីដែលយើងកំពុងធ្វើតែមួយគត់។​

ដែលចាប់អារម្មណ៍អត់ពេលដែលយើងធ្វើអ្វីមួយ​ដែលម៉ាភ្លែតសោះ ស្រាប់តែមើលម៉ោងទៅវាល្ងាចបាត់ទៅហើយ ចឹងសកម្មភាពដែលយើងធ្វើដោយមិនខ្វល់ពីអ្វីទាំងអស់ក្រៅពីការងារដែលយើងធ្វើហ្នឺងហើយគេហៅថា Flow State។

កាលពីខ្ញុំកំពុងប្រលង Certified Penetration Testing Exam របស់ Hackthebox ដែលមានរយៈពេល 10 ថ្ងៃដើម្បីបញ្ចប់ការរក flags​ ដែលសរុបទាំងអស់មាន 14 flags (12 flags is enough to pass exam) និងការសរសេររបាយការណ៍ professional-grade ដើម្បីគេវាយតម្លៃនឹងអាចជាប់ឬធ្លាក់។ កាលពីថ្ងៃទី 1 នៃការប្រលងខ្ញុំបានហេកចូលទៅកាន់ប្រព័ន្ធមួយចំនួនប៉ុន្តែ វាមិនមែនជាផ្លូវទៅកាន់ flag ទី 1 នោះទេអាចនិយាយបានថាជា Loophole, បន្ទាប់មកខ្ញុំក៏បានសម្រាកបន្ទាប់ពីបានមើលកំព្យូទ័ររយៈពេល 6 ម៉ោង។ នៅថ្ងៃបន្ទាប់ដែលជាថ្ងៃទី 2 នៃការប្រលង ខ្ញុំក៍ចាប់ផ្ដើមរកផ្លូវឃើញដើម្បីឈានទៅដល់ការរកឃើញ flag ទីមួយ។ នៅពេលដែលខ្ញុំរកបាន flag ទីមួយភ្លាមខ្ញុំក៍បានចូលស្លុងទៅកាន់ flow state ដែលក្នុងត្រឹមរយៈពេលមួយថ្ងៃប៉ុណ្ណោះ ខ្ញុំអាចរកបានរហូតដល់ 7 flags​ ដែលថាពេលហ្នឹងខ្ញុំបានចូលទៅក្នុង flow state ដែលធ្វើអោយខ្ញុំប្រមូលផ្ដុំអារម្មណ៍បានល្អនឹង បន្តទៅមុខរហូតដូចជិះ slide។

វិធីសាស្ត្រដើម្បីអាចចូលទៅក្នុង Flow State បាន៖

  1. Choose the Right Activity - ជ្រើសរើសការងារដែលផ្តល់ផលប្រយោជន៍មកអោយយើង example; you want to learn hacking, challenge ខ្លួនឯងដោយធ្វើការស្រាវជ្រាវ
  2. Set Clear Goals - ដឹងពីអ្វីដែលយើងកំពុងធ្វើ បំបែកការងារទៅជាតូចៗដែលអាចគ្រប់គ្រងបាន។ example; រៀនអោយបាន​ 1-2 វិធីសាស្រ្តដែលពួក hacker ប្រើដើម្បីជ្រៀតចូលប្រព័ន្ធ។
  3. Eliminate Distraction - ការរំខាននឹងធ្វើអោយយើងមិនអាចចូល flow state បាន។ ជ្រើសរើសកន្លែងដែលយើងអាចផ្តោតអារម្មណ៍បាន។ example; បិទ Notification ឬ​ ដាក់ phone នៅអោយឆ្ងាយពីខ្លួន, ប្រើកាសដែលមាន noise canceling, នៅកន្លែងស្ងប់ស្ងាត់ជាដើម។
  4. Focus Completely - ស្ដាប់ instrument music ឬ lofi បើយើងចូលចិត្ត
  5. Balance Challenge and Skill - ជ្រើសរើស topic ដែលនៅក្រៅ comfort zone ជួយអោយយើង motivated បើការងារស្រួលពេកប្ដូរទៅអាលំបាក។
  6. Stay Motivated with Feedback - សួរខ្លួនឯងមានឃើញពី progress ឬអត់
  7. Practice Intrinsic Motivation - Flow state កើតឡើងនៅពេលយើង enjoy នឹងសកម្មភាពដែលយើងកំពុងធ្វើ​ មិនមែនលទ្ធផលទេ បើយើងអត់ចូលចិត្តរៀនយើងគ្មាន Motivation ទេ ចឹងយើងមិនអាចចូល flow state បានទេ។

បើសួរខ្ញុំថា Motivation និង Discipline មួយណាល្អជាង ខ្ញុំជ្រើសរើសយក Discipline ប៉ុន្តែនៅមានមួយទៀតគឺ Obsession បើសិនយើង Obsessed ជាមួយអ្វីដែលយើងកំពុងធ្វើហើយនោះយើងនឹងរីកចម្រើនបានលឿន។
